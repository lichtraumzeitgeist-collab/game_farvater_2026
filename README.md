# game_farvater_2026
Браузерная 3D-игра для профориентации и знакомства с работой на производственном предприятии. HTML, CSS, JavaScript, Three.js.

## Как запустить игру

Игра использует JavaScript-модули, поэтому её нельзя запускать двойным кликом по файлу `index.html`. Необходимо открыть проект через локальный сервер. Также для загрузки Three.js требуется подключение к интернету.

### Вариант 1 — Visual Studio Code и Live Server

1. Скачайте и установите [Visual Studio Code](https://code.visualstudio.com/).
2. Установите расширение [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
3. Откройте в Visual Studio Code всю папку с игрой.
4. Найдите файл `index.html`.
5. Нажмите по нему правой кнопкой мыши.
6. Выберите **Open with Live Server**.

Игра автоматически откроется в браузере.

### Вариант 2 — Python

Откройте терминал в папке с игрой и выполните:

```bash
python -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Для остановки сервера нажмите `Ctrl+C`.

> Не запускайте игру через адрес вида `file:///.../index.html` — в таком режиме браузер может заблокировать загрузку необходимых файлов.
